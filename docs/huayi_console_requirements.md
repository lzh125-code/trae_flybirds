# 掌上华医刷课控制台 · 需求规格（v0.1 待确认）

## 0. 一句话目标

在本地浏览器里完成「选课件 → 自动播放 → 自动答题 → 归档截图 → 盘点进度」的全流程，异常时能看见、能干预，不再需要人盯着终端。

## 1. 范围

**做**
- 单设备（127.0.0.1:5555）、单账号
- 播放守护、弹窗与卡顿自愈、结束判定、自动进考试
- 全自动答题：答案库优先 → 未命中调 LLM → LLM 结果直接交卷
- 每课件 5 张截图归档、项目进度盘点
- 本地配置文件承载设备与 LLM 参数，不依赖 Trae IDE

**不做**
- 多设备并行、多账号切换（预留字段，不做交互）
- 自动提交证书申请（保留按钮 + 二次确认，人工点）
- 任何绕过学习时长/伪造进度的做法

## 2. 技术形态

- 后端：Python 3.10 + FastAPI + SQLite（状态与事件）
- 前端：单页 HTML + 原生 JS（CDN 可用时用轻量 CSS 框架，页面不依赖构建工具）
- 设备层：ADB（复用现有 `huayi_course_guard.py` 的判定逻辑，抽出为可调用模块）
- 通信：REST + SSE（事件流实时推送）
- LLM：OpenAI 兼容 `chat/completions`，配置在 `.env`

```ini
# .env（不入 git）
ADB_PATH=E:\leidian\LDPlayer14\adb.exe
HUAYI_DEVICE=127.0.0.1:5555
CONSOLE_PORT=8765
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-xxx
LLM_MODEL=deepseek-chat
LLM_TIMEOUT=60
```

## 3. 页面与功能

### 3.1 总览
- 设备卡：连接状态、当前 Activity、分辨率、最近 dump 是否正常
- 运行卡：当前课件、进度条（已播/总时长）、分片号、停滞次数、已运行时长
- 控制：开始 / 暂停 / 继续 / 停止 / 强制恢复播放
- 告警横幅：停滞 >2 分钟、心跳 >3 分钟无更新、adb 断开、答题异常
- 事件流：时间 + 类型（进度/弹窗/恢复/截图/考试/错误）+ 摘要，可筛选

### 3.2 任务队列
- 从项目盘点的课件列表勾选入队，显示每项状态：排队 / 播放中 / 待考试 / 已完成 / 失败
- 支持上移、下移、跳过、重试、删除
- 队列执行完自动停在总览，不自动提交证书
- 每课件记录耗时（播放/考试/空等），队列页显示汇总

### 3.3 考试面板
- 实时展示当前题目：题号、题干、选项、已选项
- 答案来源标识：`答案库` / `LLM` / `人工`
- 自动流程：读题 → 匹配 → 选择 → 核对 `checked` → 交卷 → 读结果
- 未通过：记录错题（题干+所选+正确答案若可得），自动重考一次，仍失败则暂停任务并告警
- 人工干预：任一题可改为人工选择，改完继续自动流程
- 答案库管理：列表、搜索、新增/编辑/删除，字段 `题干 / 选项 / 正确项 / 来源 / 更新时间`

### 3.4 证据与盘点
- 按「项目 / 课件」两级展示，每个课件 5 个槽位：开始、中间、结束、考试开始、考试结果
- 缺失槽位标红，可单张补截；点击看大图
- 盘点结果表：课件名、状态（已完成/学习中/待考试/未开始）、进度、截图齐全度
- 「待考试」标注为不可信状态：以进入课件后的真实进度为准

### 3.5 设置
- 设备与 adb 路径（修改后即时体检）
- LLM 参数：测试连接按钮，显示返回的模型名
- 路径设置：任务根目录、日志路径
- 证书申请：独立按钮，弹窗二次确认，写入事件流

## 4. 自动化状态机

```
IDLE → PLAYING → ENDED → EXAM_OPEN → ANSWERING → SUBMITTED
                   ↑                        ↓
                RECOVERING ←── STALLED / 掉回项目页 / 弹窗遮挡
```

规则（沿用已实测结论）：
1. 进度以 logcat `_N.ts` 序号 × 8.57s 估算，取**最后一条**而非最大值
2. 结束：出现「谢谢观看」或「请点击左下角"考试"」；否则停滞 ≥5 分钟且进度 ≥85%
3. 停滞 2 轮即 `keyevent 126` 恢复，10 轮告警
4. 禁止点「确定」（会退回项目页）；弹窗按子串匹配白名单
5. 检测到测验页后停止一切盲点，只做读题与选答
6. 答题按题干文本匹配，不依赖固定顺序

## 5. 数据表（SQLite）

- `tasks`：id、项目名、课件序号、课件名、状态、时长、已播、分片号、开始/结束时间
- `events`：id、task_id、时间、类型、内容
- `answers`：id、题干(归一化)、选项 JSON、正确项、来源、命中次数、更新时间
- `exam_runs`：id、task_id、题目 JSON、来源、得分、结果、耗时

## 6. 验收标准

1. 页面能启动守护、暂停、停止，状态 3 秒内反映到界面
2. 拔掉 adb 后 60 秒内出现「设备断开」告警，恢复后自动继续
3. 队列 3 个课件可无人值守连播，每个课件截图 5 张齐全
4. 考试 5 题在答案库命中时全自动通过；未命中时由 LLM 作答并交卷，结果留痕
5. LLM 配置只改 `.env`，重启服务即生效，不依赖 IDE
6. 全流程任何自动动作都能在事件流里追溯到时间与原因

## 7. 实施顺序

1. 骨架：FastAPI + SQLite + SSE + 总览页，能启停现有守护脚本
2. 任务队列 + 课件盘点
3. 考试面板 + 答案库 + LLM 兜底
4. 证据画廊 + 耗时报表
5. 自检：按第 6 节逐条跑一遍

## 8. 已确认决策

| 议题 | 结论 |
| --- | --- |
| 产品形态 | 本地 Web 控制台（Python 起服务，浏览器访问） |
| 设备与账号 | 先单设备单账号，字段预留多设备 |
| 答题自动化 | 答案库优先，未命中调 LLM，LLM 结果直接交卷 |
| 考试未通过 | 自动重考一次并记录错题，仍失败则暂停队列并告警 |
| LLM 配置 | OpenAI 兼容接口，密钥与地址放 `.env`，不依赖 Trae IDE |
| 第一版模块 | 实时监控与控制、任务队列、考试面板、证据与盘点、设置 |
| 证书申请 | 保持人工，按钮 + 二次确认 |
